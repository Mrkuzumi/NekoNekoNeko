## 轮次 2：实现 CPU 温度读取

**使用模式**：Ask

**我的提示词**：
```
树莓派的CPU温度在 /sys/class/thermal/thermal_zone0/temp 里是个五位整数（如30667），
如何正确转换为摄氏度？
```

**AI 关键回复要点**：
除以 1000 得到浮点数。用 fopen 读取文件，fscanf 取整数，除以 1000.0f。建议用 if(fp) 检查文件是否存在，不存在时返回 -1 表示读取失败。

**我的判断与后续行动**：
采纳并加了温度异常处理，如果传感器不存在显示 N/A。

## 轮次 3：实现 /proc/meminfo 解析

**使用模式**：Ask

**我的提示词**：
```
/proc/meminfo 里面有很多行，我只想要 MemTotal 和 MemAvailable，
怎么用 C 语言只提取这两个字段？
```

**AI 关键回复要点**：
用 fgets 逐行读取，用 sscanf 匹配 "MemTotal: %lu kB" 和 "MemAvailable: %lu kB"，匹配成功则 continue 跳过后续处理。优点是健壮，不依赖行号顺序。

**我的判断与后续行动**：
实现了逐行扫描方式，代码比想象中简洁。

## 轮次 4：进度条显示

**使用模式**：Code

**我的提示词**：
```
我想在显示内存和磁盘使用率时，在数字旁边画一个ASCII进度条，
比如 [#####.....] 67%，用C语言怎么写？
```

**AI 关键回复要点**：
根据百分比计算填充长度：`int fill = (int)(percent * width / 100);`，循环输出 filled/empty 字符。注意处理 fill 超出 width 和小于 0 的边界情况。

**我的判断与后续行动**：
实现后调用 `printBar(info->memPercent, 20, "#", ".")`，显示效果很好。

## 轮次 5：日志文件格式

**使用模式**：Plan

**我的提示词**：
```
我想把每次采样的数据保存到文件里方便以后查看，日志应该用什么格式？
读取时要注意什么？
```

**AI 关键回复要点**：
推荐用 `|` 分隔的文本格式：`timestamp|cpuTemp|load|memPct|diskPct|memUsedKB|diskUsedKB`。用 fprintf 追加写入，sscanf 读取。建议限制日志条目数量避免文件过大。

**我的判断与后续行动**：
采纳了 `|` 分隔方案。使用 MAX_LOG_ENTRIES=100 限制读取条数。

## 轮次 6：实时监控模式

## 轮次 10：磁盘信息读取

**使用模式**：Ask

**我的提示词**：
```
我想获取树莓派的磁盘使用情况，用 system("df -h") 还是什么方式比较好？
```

**AI 关键回复要点**：
不要用 system("df")，这样会创建子进程且输出解析麻烦。推荐用 POSIX 函数 statvfs()，它直接返回文件系统统计信息，不依赖外部命令。需要 #include <sys/statvfs.h>。

**我的判断与后续行动**：
改用 statvfs() 实现，代码更简洁、更稳定、不依赖外部命令。
