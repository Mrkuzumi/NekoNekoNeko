## 第一轮：1.1 代码理解

**我**：
有一段 C 语言代码我看不太懂，帮我看看它到底在干啥。代码大概是读一个 n，然后读一堆学生的数据，好像算了什么分，最后输出了一堆东西。你能帮我写个提示词吗，我拿去让别的 AI 写个功能一样的程序出来？

**AI**：
看了你的代码，它做的是一个学生活跃度评分系统。具体来说：

1. 读入 n 个学生，每人 5 个数据：学号、发帖数、评论数、礼物数、迟到次数
2. 用公式算分：`发帖×0.01 + 评论×2.5 + 礼物×8 - 迟到×1.5`，负数归零
3. 输出平均分、三个等级人数（hot≥300, warm≥100, cold<100）
4. 输出最高分和最低分的学生
5. 按分数降序排列所有学生（分数相同按学号升序）

提示词你可以这样写：
> 请用 C 语言写一个命令行程序：读取 n 个学生（n≤100），每人 5 个整数（学号、发帖、评论、礼物、迟到），按公式 `score = 发帖×0.01 + 评论×2.5 + 礼物×8.0 - 迟到×1.5` 计算得分，负数归零。输出：平均分（保留两位）、hot/warm/cold 人数、最高/最低分学生学号和得分（保留一位）、全部学生按得分降序排列（并列按学号升序）。

有个细节初学者容易漏：`score[i] < 0` 归零这个操作必须在累加 sum 之前做，不然平均值和排序都会错。还有那个排序的次级条件 `no[j] > no[j+1]` 方向容易写反。

## 第三轮：2.1 弹跳小球

**我**：
物理题，一个小球从 h 厘米高度掉下来，每次弹起来的高度是当前高度的 p/q 然后向下取整，弹到 0 就停。让我输出落地次数和总共走了多少路。帮我写个 C 程序呗。

**AI**：
这个题目逻辑很简单，一个 while 循环就行：

```c
int h, p, q;
scanf("%d %d %d", &h, &p, &q);
int landings = 0, total = 0, cur = h;
while (1) {
    landings++;
    total += cur;                    // 下落距离
    int rebound = (cur * p) / q;     // 整数除法自动向下取整
    if (rebound == 0) break;
    total += rebound;                // 反弹上升距离
    cur = rebound;
}
printf("%d %d", landings, total);
```

注意输出只有两个整数，不要加什么"落地次数："之类的多余文字，题目要求严格。

样例 `100 1 2` 会输出 `7 294`。

**我**：
好的跑了一下没问题。那个 total 第一次加的是下落，第二次加的是反弹，这样来回加刚好就是总路程对吧。

## 第四轮：2.2 欧姆定律

**我**：

**AI**：
好的，这个题遍历一遍就行，关键点：

- 无效记录直接跳过，不参与任何统计
- 误差公式用 `abs(U - R * I)`
- 最小误差记录编号从 1 开始，用 `<` 比较保证并列取先出现
- 没有有效记录时输出 `-1 0`
- 电压电流总和可能很大，建议用 `long long`

输入输出样例你自己验证一下。注意输出格式严格三行，不要加解释性文字。

**我**：
有了有了，我拿给的样例测了输出是对的。

## 第七轮：修中文乱码

**我**：

**AI**：
Windows 终端默认是 GBK 编码，源码又是 UTF-8，所以中文变乱码。在 main 函数开头加一行 `system("chcp 65001 > nul")` 就行，把终端切成 UTF-8。

**我**：
那 q2_1 和 q2_2 不用加吗？

**AI**：
那俩只输出数字，没中文，不用改。q1_2、q3_1、q3_2 有中文才需要。

加了之后好了，中文能显示了。
