## 1.1 代码理解与需求反推
阅读下面代码，请写一段会发给AI工具的提示词，让AI写出功能一致的程序；并写出一个你认为初学者或AI容易忽略的细节。
```c
#include <stdio.h>
#define MAXN 100

int main(void){
    int n,i,j;
    int no[MAXN],words[MAXN],comments[MAXN],gifts[MAXN],late[MAXN];
    double score[MAXN],sum=0.0;
    int hot=0,warm=0,cold=0,maxIndex=0,minIndex=0;
    if(scanf("%d",&n)!=1||n<=0||n>MAXN)return 0;
    for(i=0;i<n;i++){
        scanf("%d%d%d%d%d",&no[i],&words[i],&comments[i],&gifts[i],&late[i]);
        if(words[i]<=0||comments[i]<0||gifts[i]<0||late[i]<0)return 0;
        score[i]=words[i]*0.01+comments[i]*2.5+gifts[i]*8.0-late[i]*1.5;
        if(score[i]<0)score[i]=0;
        sum+=score[i];
        if(score[i]>=300)hot++;
        else if(score[i]>=100)warm++;
        else cold++;
        if(score[i]>score[maxIndex])maxIndex=i;
        if(score[i]<score[minIndex])minIndex=i;
    }
    printf("%.2f\n",sum/n);
    printf("%d %d %d\n",hot,warm,cold);
    printf("%d %.1f\n",no[maxIndex],score[maxIndex]);
    printf("%d %.1f\n",no[minIndex],score[minIndex]);
    for(i=0;i<n-1;i++){
        for(j=0;j<n-1-i;j++){
            if(score[j]<score[j+1]||(score[j]==score[j+1]&&no[j]>no[j+1])){
                int tn=no[j],tw=words[j],tc=comments[j],tg=gifts[j],tl=late[j];
                double ts=score[j];
                no[j]=no[j+1]; words[j]=words[j+1];
                comments[j]=comments[j+1]; gifts[j]=gifts[j+1]; late[j]=late[j+1];
                score[j]=score[j+1];
                no[j+1]=tn; words[j+1]=tw; comments[j+1]=tc; gifts[j+1]=tg; late[j+1]=tl;
                score[j+1]=ts;
            }
        }
    }
    for(i=0;i<n;i++){
        printf("%d%d%d%d%d %.1f\n",no[i],words[i],comments[i],gifts[i],late[i],score[i]);
    }
    return 0;
}
```

2.1 编程题：会停下来的小球（本题仅需提交代码）
物理课上做小球弹跳实验。一个小球从 h 厘米高度自由落下，第一次落地后，如果还能反弹，则反弹高度变为当前高度的 p/q，并向下取整为整数厘米。之后每次落地后都按同样规则计算下一次反弹高度。当某次落地后的反弹高度变为 0 时，实验结束。请输出小球一共落地多少次，以及整个过程中经过的总路程。
输入：一行 3 个正整数 h p q，保证 p < q。
输出：两个整数。第一个表示小球落地次数，第二个表示小球经过的总路程，单位为厘米。
说明：总路程包含第一次下落的距离，也包含每次有效反弹的上升和再次下落距离。
样例输入：
plaintext
100 1 2
样例输出：
plaintext
7 294
2.2 编程题：欧姆定律实验记录
一次物理实验中，同学们用同一个电阻做多组测量。理论上电压 U 应接近 R I。现在有若干条实验记录，需要你筛选有效记录，并统计哪些记录近似符合欧姆定律。请写程序统计有效实验记录数、达标记录数、不达标记录数、有效记录的电压电流总和，以及误差最小的记录。
输入
第一行是 3 个整数 n R limit，表示记录数、理论电阻值和允许的最大电压误差。
接下来 n 行，每行 3 个整数：U I flag
其中 U 表示测得电压，I 表示测得电流，flag 表示仪器状态。若 U <= 0、I <= 0 或 flag != 0，该记录无效，不计入统计。
对一条有效记录，误差定义为：abs (U - R * I)
若误差小于等于 limit，则认为该记录达标。
输出
输出 3 行：
第一行输出有效记录数、达标记录数、不达标记录数。
第二行输出有效记录的电压总和与电流总和。
第三行输出误差最小的有效记录编号和误差；如果没有有效记录，输出 - 1 0。记录编号从 1 开始，若误差并列，输出较早出现的记录编号。
样例输入：
plaintext
7 5 3
50 10 0
51 10 0
80 15 0
30 6 1
-5 3 0
44 9 0
25 4 0
